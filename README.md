## Overview

Zestora Juice Bar is a modern and visually appealing juice bar website designed to promote healthy beverages and natural lifestyles. The project features a vibrant user interface, product showcases, promotional sections, customer engagement elements, and a fully responsive design.

The website was developed to provide an attractive digital presence for a juice bar business while demonstrating modern frontend development skills and responsive web design principles.

## Installation

Clone the repository:

```bash
git clone https://github.com/senuja1/zestora-juice-bar.git
```

Navigate to the project directory:

```bash
cd zestora-juice-bar
```

Open the project using:

```bash
index.html
```

Or run it using VS Code Live Server.
